# 关于我 / About Me

你好！我是 **水江梓**，这里是我的个人博客 **Kasaki Blog**。

我会在这里记录学习、生活、技术实践以及其他值得分享的内容。

## 🛠️ 关于本站

本站使用 **Astro** 构建，采用 [Firefly](https://github.com/CuteLeaf/Firefly) 作为主要主题基础。

本站的组件设计和相关代码来自 Firefly，当前网页属于基于 Firefly 的二次创作。感谢 Firefly 项目及其贡献者提供的开源设计与实现。

Firefly 基于 [Fuwari](https://github.com/saicaca/fuwari) 进行二次开发，并提供了丰富的博客布局、主题配置和 Markdown 扩展能力。

- [Firefly 官方仓库](https://github.com/CuteLeaf/Firefly)
- [Firefly 使用文档](https://docs-firefly.cuteleaf.cn/)
- [Fuwari 官方仓库](https://github.com/saicaca/fuwari)
